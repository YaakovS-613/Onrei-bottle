# Onrei-bottle

This repository contains an Arduino‑based temperature control prototype developed for a school competition. The system uses a DS18B20 sensor for temperature measurement, an SSD1306 OLED for display output, and two buttons for adjusting the target temperature or switching between Fahrenheit and Celsius. Heating and cooling are performed using Peltier modules driven by two digital output pins.

## Features
- DS18B20 temperature sensing  
- SSD1306 OLED display interface  
- Adjustable set temperature  
- °F/°C mode toggle  
- Automatic heating/cooling control using Peltier modules  

## Hardware
- Arduino (Uno/Nano/etc.)  
- DS18B20 temperature sensor  
- SSD1306 128×64 OLED (I2C)  
- Two push buttons  
- Peltier modules  
- Two digital output pins for heat/cool control
